### 构建链（重要）
- **`lib/client.js` 是构建产物** —— `scripts/build.mjs` 用 esbuild 把 **`src/client.js`（人读源码，407 KB）** 压缩成 **`lib/client.js`（运行产物，250 KB）**。
- 文件头写明：`This file is generated from src/client.js via node scripts/build.mjs. Do not edit directly.`
- **host 侧（`lib/*.js` 除 client.js 外）是手写源码，直接改。**

### 🔴 硬约束：客户端单文件上限 256 KB
`build.mjs` 末尾有一条**强制校验**：

```
if (result.code.length > 262144) → 报错并 exit 1
（"DSH STORE per-file bound"）
```

| | 字节 |
|---|---|
| 上限 | **262144**（256 KB） |
| 上游 1.6.12 产物 | 249864（只剩 **12.3 KB** 余量） |
| **我们上次改完的产物** | **233265**（余 **28.9 KB**） |

⇒ **加功能不是随便加**：客户端每加一块 UI，都在吃这 28.9 KB。这是"重新制作"时必须先知道的边界。

## 五、与 DSH 内置用量显示的边界（别混淆）

**DSH 本身已自带**用量显示：TTFT · tok/s · 轮次步数 · 上下文压力 · 上下文组成。
**cost-meter 与它是互补关系**：内置管 **token 与上下文**，本插件管 **"钱"与历史**。
