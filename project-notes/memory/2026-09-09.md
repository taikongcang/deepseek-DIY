## 会话目录命名机制查清（用户想改成"日期+时间"方便查找删除）
- **三层结构**：`sessions/<projectKey(cwd)>/<encodeSegment(sessionId)>/session.jsonl.zstd`。
  - 第一层 projectKey(cwd)：按项目目录分组（所有对话共用），`/ \ :` 变 `-`，中文等非安全字符变 `~XXXX` 转义 → 这就是 `--I-deepseekharness-AI~80A1~7968--`（"股票"=80A1/7968）的来源。
  - 第二层 encodeSegment(sessionId)：**每次新建对话生成的那层**，sessionId 来自 `dsh-api-session-controller/lib/index.js:577` `sessionId = request.sessionId ?? SessionId(\`session-${randomUUID()}\`)`；fork 子会话在 692 行同样 `session-${randomUUID()}`。这就是 `session-c660ad16-...` 那串"奇怪"名字的来源。
  - 第三层：文件名写死 `session.jsonl.zstd`（logPath 里 `session${logSuffix}`），与 id 无关。
- **硬约束**：sessionId 是全系统唯一主键（写进 header `id:`、用于恢复/去重/查找/fork 父子关联/标题关联），不能改纯"日期+时间"（同秒撞 id）。正确做法 = `session-日期时间-短随机` 前缀+随机保唯一。
- **改动点**：官方核心包 `@deepseek-ai/dsh-api-session-controller` 577 行 + 692 行，走 patches 补丁（resolutions 里 `patch:...` 协议，与中文化补丁同一套），不动原包。目录名不能用 `:`（会转义 ~003A），用 `-`/`.` 分隔。
- 命名逻辑源码在 vendor tgz `deepseek-ai-dsh-session-persistence-jsonl` 的 lib/index.js（encodeSegment/projectKey/logPath 三函数）。
