## 待办 2 实锤：局域网访问开关置灰根因（17:20，已完成·查看）
- 结论：**不是 bug，是设计限制**。浏览器访问 + 局域网访问这两个开关只在 shell 模式 = `compatibility`（兼容）时开放。
- 机制链（desktop-network.ts:25-38）：`desktopBrowserAccessAvailable(mode)` 只有 `mode==='compatibility'` 才 true → "允许在浏览器中打开"开关 disabled=`!available`（DesktopSettingsSection.tsx:675）→ browserAccess=false → "局域网访问"开关 disabled=`!browserAccess`（:683）。
- **实锤你的现状**：`I:\deepseek-harness\.dsh\settings.yaml:3-6` 写的是 `dsh-desktop: { networkExposure: loopback, openBrowser: false, mode: extended }`——**你当前是 extended（扩展）模式**，所以两开关都置灰。
- shell 模式 3 种：compatibility(兼容)/extended(扩展)/advanced(高级)，默认 compatibility（profile.ts:88）。要解锁两开关需把模式切成 compatibility（设置里有切换入口，DesktopSettingsSection.tsx:615-618），切换要重启。
