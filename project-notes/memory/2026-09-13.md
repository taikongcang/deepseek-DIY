## 【查证】官方数据目录（DSH home）默认位置与优先级
官方包 `@deepseek-ai/dsh-home-paths`（`lib/index.js` 实测）：
- `DSH_HOME_DIR_NAME = ".dsh"`；`defaultDshHome() = join(homedir(), ".dsh")`
- **Windows 上 `homedir()` = `C:\Users\<用户名>`** → **默认 DSH home = `C:\Users\50667\.dsh`（系统盘！）**
- `resolveDshHome(configured, env)` 优先级（高→低）：① 显式配置路径 ② `$DSH_HOME` 环境变量 ③ 默认 `~/.dsh`（空白 DSH_HOME 视为未设）
- 桌面版自身数据：`desktopUserDataDir = app.getPath('userData')` = `%APPDATA%\<产品名>`（也在 C 盘）
- 新版 main.ts 主流程（689-705）：`resolveDesktopDataDirectory(desktopUserDataDir, fallbackHome, fallbackSource)` → 若 `data-directory/state.json` 存在则**以它记录为准**（最高优先级），否则用 fallbackHome（即 DSH_HOME 或 ~/.dsh）→ 最后 `process.env.DSH_HOME = homeDir`
- → **结论：官方默认存 C 盘用户目录，不是"其他盘"，也没有"启动时弹对话框选目录"；切换数据目录是"恢复助手"里的功能。**
