### 二、`0.2.0` 更新了什么（相对 `0.1.7-rc.2`）

**新增**
1. ⭐ **桌面端内置 `dsh` 命令**（菜单栏「管理 dsh 命令」），**可直接管理插件，无需另装 Node 或 pnpm** —— 与我们正在讨论的 **N8「装回来的入口」直接相关**
2. 自动化任务（定时任务）改由**可选插件包**提供
3. Windows 内置沙箱新增**权限诊断技能**（定位访问被拒原因，限定目录内带备份、可恢复的修复）
4. 模型选择器在模型较多时**支持搜索**（模糊匹配 + 键盘选择）
5. 侧栏文件页可直接用**本地应用打开当前文件夹**（记住选择）
6. 使用 DeepSeek 账号模型的会话**无需额外 API Key 即可网页搜索**
7. 实验性**异步问答模式**（超时后 Agent 可继续独立工作，用户可稍后回答；需手动配置开启）
8. 第三方模型目录更新至 `pi-ai 0.87.1`（**部分旧模型 ID 被移除，已保存的选择可能需重选**）

**修复（值得注意的几条）**
- 桌面端**弹窗/菜单/浮动面板避让标题栏**；小窗口与全屏切换的内容遮挡
- Windows「在文件资源管理器中打开」可能开隐藏窗口、无响应
- 工具调度异常后对话无法继续
- macOS 缺少录音权限影响麦克风授权

**调整**
- Windows 沙箱权限脚本改为**一次授权完成诊断与修复**（保留修改前备份和恢复命令）
- Bash/PowerShell 工具提示加强：**删除或移动前核对实际目标路径**

### 三、`0.2.1-alpha.1`（今天，最新）更新了什么

**新增**
1. ⭐ **实验性 Claude Code Mods 兼容层** —— 官方自述"目的是验证 **Claude Code Mods API 大致是 DSH 插件的子集**"，而非提供完整兼容
2. ⭐ **插件管理页新增「让 Agent 创建插件」入口** —— 可保留草稿进入**创造模式**，发送需求后才执行
3. 新会话支持**预填未发送的提示**；恢复草稿或跨工作区移动时保留文件/目录/会话引用
4. Markdown 预览把 **YAML 头部元数据显示为字段列表**
5. Web 支持 `--public-url`（显示/打开/给模型的对外地址，支持带路径前缀的反向代理）
6. 可选**开发者工具组合包**（会话原始日志、聊天分组与正文双向定位、内嵌 Host 调试工具；DevTools 目前英文界面）

**⚠️ 破坏性变更（对插件作者）**
1. **移除运行时 invariant 插件**及各包的 `./invariant` 导出 ⇒ 依赖它的扩展和自定义 profile 需调整
2. ⭐ **输入区统计扩展拆为 `activity` 和 `usage` 两个独立入口** ⇒ **覆盖旧 `stats` 整行的插件需要更新注册 ID**（**直接影响我们的 N33 用量管理 / cost-meter 类插件**）
3. 子路径插件不再读取独立的 `package.json`，显示文本和图标须通过对应子路径导出
4. 自动化任务改为 Web 内置能力，提醒工具仅在标准/创造/PTC 模式可用

**修复 / 优化**
- **桌面端默认使用系统分配端口，避免 Windows 保留端口范围导致应用无法启动**（❗这条解释了官方为何要改 19387 那套）
- 修复启停插件时**其他插件的样式被移除、需刷新页面**的问题
- 修复新组合包启用后找不到依赖、停用后残留依赖映射
- 插件安装结果显示**实际安装版本**；有**新版本冷却策略**（装旧版时给出说明与精确版本安装方式）
