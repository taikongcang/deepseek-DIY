## ⭐⭐ 头条：官方**有桌面版** —— 我们档案里一条核心结论被推翻

**原记录（2026-09-15，`tech-notes.md` §〇）**：「⚠️ 官方**根本没有桌面版**：无 Electron、无"打包成 exe"的任何说明」；「Electron 桌面化（dsh-desktop）**完全是社区自创**」。

**❌ 这条是错的。** 错因：当时**只翻了 `docs/` 与 README，没有翻仓库的 `apps/` 目录** —— 把"我没找到"当成了"官方没有"。

**✅ 实测事实（2026-09-26）**：
- 官方仓库有 **`apps/desktop/`（+ `apps/desktop-host/`）**，就是 Electron 桌面版；`desktop in:path` 搜索命中 **603 条**。
- **最早提交 `19444907` = 2026-08-28 `feat: electron 打包`** —— **比我们选基座（社区 2.0.x）还早**。随后持续迭代到 **2026-09-24**（`revert(desktop): remove branch-local development launchers`）。
- 能力（读 `apps/desktop/README.zh.md`）：Electron + electron-builder；**Windows NSIS 安装器 / macOS DMG**；托盘常驻；单实例锁；`dsh-app://` 协议；独立端口 **19387**（Web 是 3080）；独占 `$DSH_HOME/profiles/desktop`；**自动更新**（`download.deepseek.com` / `nightly.yml`）；强更策略；**Windows EV 签名**（SafeNet + SignTool + DigiCert 时间戳）；macOS Developer ID + 公证。
- **版本号规则：Desktop 版本 = dsh 基础版本完全相同**。
- **自带 Python（numpy/pandas/python-docx/pptx/openpyxl/Pillow/lxml/XlsxWriter）+ Node + pnpm** 运行时，`load_workspace_dependencies` 离线安装。
- ⚠️ **但官方主 README 对用户只宣传 Web**（`npx @deepseek-ai/dsh web`），**不提桌面版**；桌面版仅出现在 `apps/desktop/README.zh.md` 与开发章节（`make help` 列 Web 与 Desktop）。其 README 自述「账号登录尚未接入」⇒ 看形态仍是**内部/受控发布**。

**⭐ 附带收获：官方文档层面直接印证了我们的 N12 结论。** `apps/desktop/README.zh.md` 原文：
> 「开发、仅准备和未签名构建不使用硬件令牌，**可能被 Windows 代码完整性策略阻止**；**任何构建模式都不会关闭该策略**。」

⇒ 连官方都承认：**未签名的 Windows 构建会被 Windows 代码完整性策略（SAC/WDAC）挡，解法就是买 EV 证书签名** —— 与 N12 完全一致。官方另有 **`DSH_DESKTOP_UNSIGNED=1`** 未签名构建模式（产物名带 `-unsigned`）。
